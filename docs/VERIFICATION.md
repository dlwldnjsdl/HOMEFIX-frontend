## 사용자 컴퓨터에서 먼저 실행할 명령

```powershell
node -v
npm install
npm run typecheck
npm run build
npm run dev
```

`npm run build`에 오류가 생기면 모든 오류 메시지를 확인해야 하며, 단지 화면이 나타난다고 빌드가 통과한 것은 아닙니다.

## 권장 통합검사 순서

1. 테스트용 USER 계정으로 가입·로그인·로그아웃·새로고침 세션 유지.
2. 사진 JPG/PNG 업로드와 API v1.1의 정확한 JSON 메타정보 확인.
3. AI 진단 요청→상태 조회→사용자 요약·분야 확인→검증된 해결 경로.
4. 서버에서 발급한 TECHNICIAN 계정으로 프로필·일정·사례를 등록하고 공개 목록 확인.
5. 상담 전달본 준비·미리보기·확인→상담→견적→중복 확인→예약·변경·수행.
6. 사진 날짜·기록·AI 비교·보고서·PDF·삭제 후 무효화 검사.
7. FR91/AC63/AI240 별도의 실제 검사표와 증거 확보.

업무 규칙(동시 예약, 권한 없는 사진, 자료 삭제, 멱등성)은 프론트엔드만으로 합격 판정할 수 없습니다.
